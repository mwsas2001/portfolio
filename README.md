# محمد وسام | Portfolio Website 🎨

موقع بورتفوليو شخصي لمصمم UI/UX مبني بـ HTML/CSS/JS خالص بدون أي مكتبات إضافية.

## 📁 هيكل الملفات
```
portfolio/
├── index.html     # الهيكل الأساسي وعناصر الصفحة
├── style.css      # جميع التنسيقات والرسوم المتحركة والتجاوب
├── app.js         # المنطق والبيانات ولوحة التحكم
└── README.md
```

## ✨ المميزات
- تصميم جريء وإبداعي بألوان زاهية
- متجاوب بالكامل مع جميع الشاشات (موبايل، تابلت، سطح المكتب)
- لوحة تحكم محمية بكلمة مرور
- إضافة وحذف المشاريع والخدمات
- البيانات تُحفظ في localStorage
- كرسر مخصص
- انيميشن scroll reveal
- تصميم RTL عربي

## 🔐 لوحة التحكم
كلمة المرور الافتراضية: `admin123`
لتغييرها: ابحث عن `DASH_PASSWORD` في `app.js`

## 🚀 النشر على GitHub Pages
1. ارفع الملفات على مستودع GitHub
2. اذهب إلى Settings > Pages
3. اختر Branch: main / root
4. الموقع سيكون متاحاً على: `https://username.github.io/repo-name`

## 🛠 التخصيص
- **الاسم والمعلومات**: عدّل في `index.html`
- **الألوان**: غيّر المتغيرات في `:root` داخل `style.css`
- **البيانات الافتراضية**: عدّل `DEFAULT_PROJECTS` و `DEFAULT_SERVICES` في `app.js`
